# Liberstack


Meu nome é Guilherme Ribeiro, desenvolvedor web com foco em JavaScript, interfaces e produtos digitais. Trabalho com HTML, CSS e JavaScript, explorando também TypeScript, Python e Node.js, além do desenvolvimento de SPAs e da integração com APIs.
