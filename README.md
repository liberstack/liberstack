# Liberstack


Meu nome é Guilherme Ribeiro, desenvolvedor web com foco em JavaScript, interfaces e produtos digitais. Trabalho com HTML, CSS e JavaScript, explorando também TypeScript, Python e Node.js, além do desenvolvimento de SPAs e da integração com APIs. Tenho interesse na construção de aplicações web, UI, experiência de uso e apresentação visual de produtos digitais, buscando combinar implementação técnica, organização e clareza. Também desenvolvo e-books técnicos sobre programação e ferramentas como Git, GitHub, Markdown e Pandoc, com foco na documentação, na estruturação do conhecimento e na comunicação técnica. Meu objetivo é explorar a interseção entre desenvolvimento web, interfaces, conteúdo técnico e criação de produtos digitais.
